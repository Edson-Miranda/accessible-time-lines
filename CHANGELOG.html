Accessible Timeline - Histórico de Atualizações

Desenvolvido por: TechTales Entertainment | Público-alvo: Pessoas com deficiência visual e usuários de leitores de tela (NVDA e JAWS).

Versão 0.2.1 (16 de outubro de 2026)

  • Isolamento Total com Chromium Embutido e Dedicado: O pacote do aplicativo agora inclui seu próprio motor Chromium portátil embutido dentro da pasta browsers/. O aplicativo possui zero uso e zero dependência dos navegadores instalados no seu computador (como Edge ou Google Chrome), mantendo seus perfis pessoais, senhas e histórico totalmente intocados e isolados.
  • Correção Definitiva de Abertura do Navegador para Login: Solucionado o problema onde o navegador não abria para login em computadores sem ambiente de desenvolvimento Python instalado. O Chromium embutido é iniciado de forma confiável e independente.
  • Alternância Rápida da Janela do Navegador (Ctrl + Shift + B): Adicionada a opção no menu Timeline e o atalho de teclado Ctrl + Shift + B para exibir ou ocultar a janela do navegador caso seja necessário realizar verificações adicionais de segurança, 2FA ou alternar de conta.
  • Verificação Automática de Atualizações em Segundo Plano: O aplicativo agora verifica silenciosamente na inicialização se há novas versões disponíveis no GitHub, além de permitir a checagem manual no menu Ajuda.
  • Nova Janela de Configurações (Ctrl + P): Adicionado o menu Opções e o diálogo de Configurações com caixa de seleção nativa para ligar ou desligar a verificação automática de atualizações na inicialização, além de salvar suas preferências de temas e efeitos sonoros permanentemente.
  • Identidade e Suporte Oficial TechTales Entertainment: Inclusão dos créditos da TechTales Entertainment no diálogo Sobre (F1), manuais e links para a página oficial: https://techtales.com.br.
  • Documentação e Changelog Acessíveis em HTML: Disponibilização tanto do manual do usuário (README.html) quanto do histórico de atualizações (CHANGELOG.html) em páginas HTML totalmente formatadas e semânticas para leitores de tela em Português e Inglês.

Versão 0.2.0 (16 de outubro de 2026)

  • Efeitos Sonoros Clássicos do TWBlue: Integração de biblioteca de áudio BASS de baixa latência com sons marcantes do TWBlue para envio, respostas, curtidas, novos posts e avisos de limite de texto. Seleção de 6 temas no menu Áudio e atalho Ctrl + Shift + S para ativar/desativar sons.
  • Ações Interativas na Timeline: Nova publicação (Ctrl + N) com contador regressivo de 280 caracteres, responder (Ctrl + R), repostar e citar (Ctrl + Shift + R ou Ctrl + Shift + C), curtir/descurtir (Ctrl + L ou tecla L) e mensagens diretas (Ctrl + D).
  • Árvore Nativa de Fluxos (Estilo TWBlue / The Qube): Exibição de conta e abas (Para você, Seguindo, Menções e Mensagens diretas) com navegação fluida por Tab, Shift + Tab e atalho global Ctrl + Win + Setas.
  • Leitura Completa nas Setas e Abertura Rápida de Links: Leitura de todo o texto sem truncamento com setas para Cima/Baixo e abertura de links com Ctrl + Enter (com seletor acessível se houver múltiplos links).
  • Pré-carregamento em Segundo Plano: Inicialização automática de todos os fluxos e transição transparente para modo 100% invisível em segundo plano após o login.

Versão 0.1.0A (14 de outubro de 2026)

  • Navegação Linear Acessível: Percorrimento rápido da linha do tempo do X usando as setas para Cima e para Baixo.
  • Leitura Limpa no NVDA e JAWS: Controles Win32 nativos que evitam anúncios duplicados ou redundâncias no sintetizador.
  • Visualização de Detalhes Completos: Pressione Enter para abrir diálogo acessível de leitura linha por linha ou cópia de texto.
  • Atualização com Preservação de Cursor: Pressione F5 para carregar novos posts mantendo a posição de leitura intacta.

Accessible Timeline - Update History

Developed by: TechTales Entertainment | Target Audience: Blind and visually impaired users navigating with screen readers (NVDA & JAWS).

Version 0.2.1 (October 16, 2026)

  • Complete Isolation with Dedicated Embedded Chromium: The application distributable package now includes its own portable Chromium engine inside the browsers/ directory. The client has zero usage and zero dependency on the personal browsers installed on your computer (such as Microsoft Edge or Google Chrome), keeping your personal accounts, passwords, and history completely untouched and isolated.
  • Reliable Login Browser Window Launch: Resolved an issue where the browser window failed to launch for the initial login on systems lacking Python developer tools. The bundled Chromium runs out of the box with zero external configuration required.
  • Browser Window Toggle Shortcut (Ctrl + Shift + B): Added a menu item under Timeline and keyboard shortcut Ctrl + Shift + B to toggle the browser window visibility whenever you need to handle security checks, 2FA, or switch accounts.
  • Background Startup Update Check: The client now silently checks for newer GitHub releases upon startup in the background, in addition to manual checks in the Help menu.
  • New Application Settings Dialog (Ctrl + P): Added the Options menu and an accessible Settings dialog with a native checkbox to enable or disable automatic startup update checks, in addition to permanently persisting your audio and theme preferences.
  • Official TechTales Entertainment Branding & Support: Embedded official TechTales Entertainment credits in the About dialog (F1), user guide, and links to the official site: https://techtales.com.br.
  • Accessible Bilingual HTML Documentation & Changelog: Both the User Guide (README.html) and Update History (CHANGELOG.html) are provided as fully semantic and accessible HTML pages for screen reader navigation in Portuguese and English.

Version 0.2.0 (October 16, 2026)

  • Classic TWBlue Sound Effects: Low-latency BASS audio engine integration delivering TWBlue sound packs for tweets, replies, retweets, likes, direct messages, incoming events, and character warnings. Selection of 6 themes in Audio menu and Ctrl + Shift + S shortcut.
  • Interactive Timeline Actions: Compose tweet (Ctrl + N) with 280-character countdown, reply (Ctrl + R), retweet/quote (Ctrl + Shift + R or Ctrl + Shift + C), like/unlike (Ctrl + L or key L), and direct message (Ctrl + D).
  • Native Streams TreeView (TWBlue / The Qube Style): Account and stream folders (For You, Following, Mentions, Direct Messages) navigable with Tab, Shift + Tab, and global stream switching via Ctrl + Win + Arrows.
  • Full Text Reading with Arrow Keys & Fast Link Opening: Complete tweet reading without truncation using arrow keys, and link opening with Ctrl + Enter with accessible link chooser.
  • Background Preloading & Silent Operation: Automated startup visit across all streams and silent headless background mode once logged in.

Version 0.1.0A (October 14, 2026)

  • Accessible Linear Navigation: Fast linear timeline browsing using Up and Down arrow keys.
  • Clean Announcements for NVDA and JAWS: Native Win32 list control delivering smooth, non-redundant screen reader speech.
  • Full Post Details Window: Press Enter to inspect complete tweet text line by line or copy contents.
  • Safe Timeline Refreshing: Press F5 to refresh tweets while maintaining current reading cursor position.
