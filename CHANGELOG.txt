Update History - Accessible Timeline

======================================================================
[PT-BR] Versão 0.2.0 (16 de outubro de 2026)
======================================================================

* Efeitos Sonoros Clássicos do TWBlue:
  O cliente agora conta com os sons marcantes do TWBlue reproduzidos com resposta imediata e alta fidelidade via biblioteca de áudio BASS. Há sons para envio de posts, respostas, reposts, curtidas, mensagens diretas, recebimento de novos itens, avisos de limite de texto e alertas de erro.
  Você pode ativar ou silenciar os sons a qualquer momento com o atalho Ctrl + Shift + S ou escolher entre 6 pacotes sonoros no menu Áudio: Padrão (TWBlue), Clássico, Qwitter, Magical Fountain, FreakyBlue e FightingGames.

* Comandos e Ações Interativas no X (Twitter):
  Agora é possível interagir diretamente com a rede sem sair da interface acessível, usando o novo menu Ações ou atalhos rápidos do teclado:
  - Nova publicação: Pressione Ctrl + N para redigir um tweet. O diálogo conta com contador dinâmico regressivo de 280 caracteres e envio com Ctrl + Enter.
  - Responder: Pressione Ctrl + R para responder à publicação selecionada, com campo de leitura do tweet original.
  - Repostar e Citar: Pressione Ctrl + Shift + R para escolher entre repostar diretamente ou citar com comentário, ou Ctrl + Shift + C para abrir direto o diálogo de citação.
  - Curtir e Descurtir: Pressione Ctrl + L ou simplesmente a letra L para curtir ou remover a curtida da publicação selecionada.
  - Mensagem Direta (DM): Pressione Ctrl + D para enviar uma mensagem privada para o autor selecionado ou digitar um destinatário.

* Navegação por Árvore de Fluxos (Estilo TWBlue / The Qube):
  A interface foi aprimorada com uma árvore nativa à esquerda que exibe sua conta conectada e seus respectivos fluxos: "Para você", "Seguindo", "Menções" e "Mensagens diretas".
  - Pressione Tab na árvore para ir direto à lista de publicações do fluxo escolhido.
  - Pressione Shift + Tab na lista de publicações para voltar à árvore de fluxos.
  - Pressione Control + Windows + Setas em qualquer lugar do aplicativo para alternar instantaneamente entre os fluxos.

* Leitura Completa nas Setas e Abertura Rápida de Links:
  - O leitor de telas agora lê todo o conteúdo da publicação simplesmente navegando com as setas para Cima e para Baixo na lista, sem truncamento de texto.
  - Pressione Control + Enter em qualquer publicação para abrir seus links no navegador padrão. Se houver mais de um link, uma caixa de seleção acessível é exibida para você escolher facilmente qual link deseja abrir.

* Inicialização Otimizada e Pré-carregamento:
  Ao abrir o programa, todos os fluxos são visitados e pré-carregados automaticamente em segundo plano, evitando listas vazias.
  O navegador opera de maneira 100% invisível em segundo plano após o login inicial, sem janelas visíveis nem disputa de foco com o leitor de tela.


======================================================================
[EN-US] Version 0.2.0 (October 16, 2026)
======================================================================

* Classic TWBlue Sound Effects:
  The client now features the beloved TWBlue sound packs powered by the low-latency BASS audio engine. Sounds are triggered on sending posts, replies, retweets, likes, direct messages, receiving new timeline events, character limits, and error notifications.
  You can mute or unmute sound effects at any time using Ctrl + Shift + S or select among 6 sound packs in the Audio menu: Default (TWBlue), Classic, Qwitter, Magical Fountain, FreakyBlue, and FightingGames.

* Interactive Actions and Commands on X (Twitter):
  Interact directly with X without leaving the accessible interface, using the Actions menu or fast keyboard shortcuts:
  - New Post: Press Ctrl + N to compose a post with a live 280-character countdown and send with Ctrl + Enter.
  - Reply: Press Ctrl + R to reply to the selected post, with an accessible view of the original tweet text.
  - Retweet & Quote: Press Ctrl + Shift + R to choose between direct retweet or quoting with comments, or Ctrl + Shift + C to jump straight to quoting.
  - Like & Unlike: Press Ctrl + L or simply the letter L to like or unlike the selected post.
  - Direct Message (DM): Press Ctrl + D to send a private direct message to the author or enter a recipient username.

* Stream Tree Navigation (TWBlue / The Qube Style):
  The interface has been redesigned with a native Windows TreeView on the left showcasing your connected account and streams: "For you", "Following", "Mentions", and "Direct Messages".
  - Press Tab in the TreeView to move keyboard focus directly to the active stream post list.
  - Press Shift + Tab in the post list to return to the streams tree.
  - Press Control + Windows + Arrow Keys anywhere to switch quickly between streams.

* Full Text Reading with Arrow Keys & Fast Link Opening:
  - Screen readers now read the complete tweet text without truncation simply by moving Up and Down with arrow keys in the list.
  - Press Control + Enter on any post to open its links in your default web browser. If a post contains multiple links, an accessible selection dialog lets you choose which one to open.

* Background Preloading & Silent Operation:
  When the application starts, all streams are visited and preloaded in the background to ensure lists are immediately populated.
  Once authenticated, the browser runs 100% silently in headless background mode, without extra windows or screen reader focus stealing.

[PT-BR] Versão 0.1.0A (14 de outubro de 2026)
======================================================================

* Navegação linear pelas publicações do X (antigo Twitter):
  Use as setas para Cima e para Baixo do teclado para percorrer a linha do tempo com agilidade.

* Leitura limpa no NVDA e JAWS:
  O leitor de tela anuncia diretamente o autor, o nome de usuário (@arroba), o horário da publicação, o texto e os contadores de curtidas e repostagens, sem anúncios duplicados.

* Detalhes completos da publicação:
  Pressione Enter em qualquer publicação para abrir uma janela com o texto completo. Ali é possível ler linha por linha ou palavra por palavra com as setas, conferir links e anexos, ou copiar o texto. Pressione Escape para retornar à lista.

* Atualização da timeline:
  Pressione F5 a qualquer momento para carregar novas postagens. A publicação que você estava lendo permanece selecionada, sem saltos repentinos no cursor.

[EN-US] Version 0.1.0A (October 14, 2026)
======================================================================

* Linear keyboard navigation through X posts:
  Use Up and Down arrow keys to browse your timeline quickly and smoothly.

* Clean screen reader output in NVDA and JAWS:
  Native Win32 list control delivers clean announcements (author, handle, relative time, post text, and stats) without double speech.

* Full post details dialog:
  Press Enter on any post to open a full multi-line read dialog to navigate line-by-line, character-by-character, or copy text.

* Safe timeline refreshing:
  Press F5 to refresh posts while keeping your current reading position preserved.
