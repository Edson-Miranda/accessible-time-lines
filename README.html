Accessible Timeline - Cliente Acessível para X (Twitter)

Versão: 0.2.0 | Público-alvo: Pessoas com deficiência visual e usuários de leitores de tela (NVDA e JAWS).

Sobre o Projeto

O Accessible Timeline é um cliente concebido especificamente para oferecer navegação rápida, linear, desobstruída e 100% operável por teclado, eliminando o atrito das interfaces web modernas. Inspirado no legado consagrado de clientes como TWBlue e The Qube, o projeto prioriza controles nativos do Windows para uma experiência de fala limpa e sem redundâncias nos leitores de tela.

Novidades da Versão 0.2.0

  • Efeitos Sonoros do TWBlue: Sons clássicos para ações de envio, recebimento, curtidas, mensagens diretas, limites de texto e erros, com motor de áudio BASS de baixa latência.
  • 6 Temas Sonoros Disponíveis: Padrão (TWBlue), Clássico, Qwitter, Magical Fountain, FreakyBlue e FightingGames (Menu Áudio ou atalho Ctrl+Shift+S).
  • Interações Completas no X: Nova postagem (Ctrl+N), responder (Ctrl+R), repostar e citar (Ctrl+Shift+R / Ctrl+Shift+C), curtir/descurtir (Ctrl+L ou tecla L) e mensagens diretas (Ctrl+D).
  • Layout em Árvore Clássico: Navegação entre fluxos ("Para você", "Seguindo", "Menções" e "Mensagens diretas") via Tab, Shift+Tab e Ctrl+Win+Setas.
  • Leitura Completa nas Setas: Leitura integral de cada tweet com as setas para Cima e Baixo, sem truncamento.
  • Abertura Rápida de Links: Control+Enter abre links no navegador padrão, com diálogo de seleção para posts com múltiplos links.
  • Navegador em Modo Invisível: Operação silenciosa em segundo plano após autenticação e pré-carregamento automático de todas as guias.

Accessible Timeline - Accessible Client for X (Twitter)

Version: 0.2.0 | Audience: Blind and visually impaired users navigating with NVDA, JAWS, or other screen readers.

About the Project

Accessible Timeline is designed specifically to bring back the fast, clean, and linear social media experience inspired by classical tools like TWBlue and The Qube. It operates using native Windows controls (Win32), ensuring responsive keyboard interactions, clean screen reader speech without echo or interruptions, and zero web interface friction.

What's New in Version 0.2.0

  • Classic TWBlue Sound Packs: Low-latency audio powered by the BASS library for actions (tweets, replies, retweets, likes, DMs, incoming updates, character limit alerts, and errors).
  • 6 Audio Themes Included: Default (TWBlue), Classic, Qwitter, Magical Fountain, FreakyBlue, and FightingGames (toggle via Audio menu or Ctrl+Shift+S).
  • Complete Interactive Actions: New tweet (Ctrl+N), reply (Ctrl+R), retweet & quote (Ctrl+Shift+R / Ctrl+Shift+C), like/unlike (Ctrl+L or key L), and direct messages (Ctrl+D).
  • Classic TreeView Layout: Seamless navigation between streams ("For you", "Following", "Mentions", and "Direct Messages") via Tab, Shift+Tab, and Ctrl+Win+Arrows.
  • Full Post Reading on Arrows: Listen to the entire tweet simply by browsing with Up and Down arrow keys without text truncation.
  • Fast Link Opening: Press Control+Enter to open post URLs in your default browser, featuring a combo box dialog when multiple links are present.
  • Silent Background Browser: Headless execution after authentication with automatic background preloading for all tabs.
